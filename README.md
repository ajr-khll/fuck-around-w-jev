# fuck-around-w-jev

Experiments with [TypeSafe](https://docs.typesafe.ai) and **Jev**, its System One model.

Jev returns typed judgments and probabilities instead of generated text, so code
owns the workflow and the model supplies semantic understanding where plain code
can't. This repo is a scratchpad for finding out what that's good for.
